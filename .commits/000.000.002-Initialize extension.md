# Initialize extension

1. Initialize extension

    https://code.visualstudio.com/api/get-started/your-first-extension

    ```sh
    npm install --global yo generator-code
    ```

    ```sh
    yo code
    ```

    ```
    ? What type of extension do you want to create? - `New Extension (JavaScript)`
    ? What's the name of your extension? - `AI Autocomplete`
    ? What's the identifier of your extension? - `ai-autocomplete`
    ? What's the description of your extension? - `The open source AI code autocomplete extension for Visual Studio Code`
    ? Enable JavaScript type checking in 'jsconfig.json'? - `No`
    ? Initialize a git repository? - `Yes`
    ? Which package manager to use? - `npm`
    ```

2. Move all files in `ai-autocomplete/ai-autocomplete` to root folder (`ai-autocomplete`)

3. Install all dependencies

    ```sh
    npm install
    ```

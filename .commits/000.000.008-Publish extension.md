# Publish extension

- Icon and Logo

    - https://icons.getbootstrap.com/

        - Change color: `fill="currentColor"` -> `fill="#0d6efd"`

        - Add margin: `viewBox="0 0 16 16"` => `viewBox="-2 -2 20 20"`

- Convert SVG to PNG

    - https://cloudconvert.com/svg-to-png

        - Width: 1024
        - Height: 1024
        - Pixel Density: 1024

        - Auto-increment version number by specifying the SemVer-compatible number or version (major, minor, or patch) to increment

            ```
            vsce publish patch
            ```

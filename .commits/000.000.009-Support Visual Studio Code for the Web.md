# Support Visual Studio Code for the Web

- Add `package.json`

    ```json
    "browser": "./extension.js",
    ```

- Install `@vscode/test-web`

    ```sh
    npm install --save-dev @vscode/test-web
    ```

    - Ignore `.vscode-test-web/**` in `.gitignore` and `.vscodeignore`

        ```
        .vscode-test-web/**
        ```

- Test

    - Windows:

        - Execute `vsc-test-web.bat`

            ```sh
            npm install --save-dev @vscode/test-web && npx playwright install && npx @vscode/test-web --extensionDevelopmentPath=. .
            ```

    - devcontainer (`vsc-test-web.sh`):

        1. Install `playwright`

            ```sh
            npx playwright install-deps
            ```

            OR

            ```sh
            apt-get install libnspr4 \
                libnss3 \
                libdbus-1-3 \
                libatk1.0-0 \
                libatk-bridge2.0-0 \
                libcups2 \
                libxkbcommon0 \
                libatspi2.0-0 \
                libxcomposite1 \
                libxdamage1 \
                libxfixes3 \
                libxrandr2 \
                libgbm1 \
                libasound2
            ```

        2. Run `@vscode/test-web`

            - Run in headless mode (`--browserType=none`)

                ```sh
                npx @vscode/test-web --extensionDevelopmentPath=. --browserType=none --host=0.0.0.0 .
                ```

            OR

            - Run in GUI

                ```sh
                apt-get update
                apt-get install -y xvfb xauth

                xvfb-run -a npx @vscode/test-web --extensionDevelopmentPath=. --host=0.0.0.0 .
                ```

        3. Open `http://localhost:3000`
